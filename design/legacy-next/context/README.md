# Contextos para IA

Esta pasta contém arquivos de contexto para uso com o GitHub Copilot e outras ferramentas de IA.

## Contextos Disponíveis

1. **[Skeleton Loading](./skeleton-loading-context.md)** - Guia completo para implementação de loading skeletons avançados, com exemplos específicos para o projeto Fantasiando.

## Como Utilizar

Ao trabalhar com o GitHub Copilot, você pode referenciar estes contextos ao fazer perguntas:

```
Usando o contexto de skeleton loading que criei, implemente um skeleton para o componente ProductCard.
```

Os arquivos de contexto estão formatados em Markdown (.md) para melhor legibilidade e estruturação.

## Estrutura dos Contextos

Cada contexto contém:

- Visão geral do conceito
- Padrões de implementação
- Exemplos específicos do projeto
- Melhores práticas
- Código de referência
