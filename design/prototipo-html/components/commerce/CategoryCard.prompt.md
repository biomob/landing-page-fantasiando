**CategoryCard** — the "Escolha por ocasião" tiles (Princesas, Festa junina, Aniversário…). 4:5 photo with a gradient base, label and model count.
```jsx
<CategoryCard label="Princesas" count={24} image="assets/vestido-princesa-rosa.png" tone="pink" />
```
Lifts on hover; image zooms slightly. Use the `assets/categoria-*.png` images.
