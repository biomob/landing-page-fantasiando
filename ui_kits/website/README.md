# Loja HTML Annapê Ateliê

Abra a raiz do projeto (`index.html`) por um servidor local para navegar pelas telas de home, categoria, produto, prova virtual, contato e conta. Este diretório contém a implementação interativa de demonstração; os assets estão em `../../assets/` e os tokens em `../../styles.css`.

O mascote coração/sol aparece no banner e nos estados da prova virtual. O banner e as fotos ilustrativas dos vestidos foram atualizados em 2026-09-29. Os dados da loja e os fluxos de compra e prova virtual são simulações, conforme o `README.md` da raiz.
